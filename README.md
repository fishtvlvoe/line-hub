# LINE Hub

A WordPress integration hub for LINE — handling login, OAuth, notifications, and webhook management.

## Features

- LINE login and OAuth authentication
- Automatic WordPress account registration
- Email capture and verification
- Multi-scenario message notifications (orders, shipments, members)
- Webhook management
- Third-party plugin integration (FluentCart, BuyGo+1)

## Requirements

- WordPress 6.5+
- PHP 8.2+
- MySQL 5.7+ / MariaDB 10.3+

## Installation

1. Upload the plugin folder to `/wp-content/plugins/line-hub/`
2. Activate the plugin in the WordPress admin
3. Go to "LINE Hub" > "Getting Started" to configure

# LINE Hub

WordPress 的 LINE 整合中樞外掛，統一處理登入、OAuth、通知與 Webhook 管理。

## 功能

- LINE 登入與 OAuth 認證
- WordPress 帳號自動註冊
- Email 擷取與驗證
- 多場景訊息通知（訂單、出貨、會員）
- Webhook 統一管理
- 第三方外掛整合（FluentCart、BuyGo+1）

## 系統需求

- WordPress 6.5+
- PHP 8.2+
- MySQL 5.7+ / MariaDB 10.3+

## 安裝

1. 上傳外掛資料夾至 `/wp-content/plugins/line-hub/`
2. 在 WordPress 後台啟用外掛
3. 前往「LINE Hub」→「入門」開始設定
